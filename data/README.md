# Data

**No dataset files are redistributed in this repository.** They are generated from the public
ShuttleSet releases by `build_dataset.py`. This folder keeps only the small metadata files that
document the sample used in the paper.

| File | Contents |
|---|---|
| `dataset_report.json` | Sample composition reported in Table 1 (matches, games, rallies) |
| `train_match_ids_v2.txt`, `val_match_ids_v2.txt`, `test_match_ids_v2.txt` | Match-level grouped split |

Generated by `build_dataset.py` (not tracked in git):

| File | Contents |
|---|---|
| `dataset_blsr_v2.csv` | One row per stroke, 91,636 rows; columns: `game_id`, `rally_id`, `match_id`, `is_target_turn`, `aroundhead`, `backhand`, `time_proportion`, `roundscore_diff`, `continuous_score`, `hit_area`, `player_location_area`, `opponent_location_area`, `type`, `is_target_win` |
| `macro_features_v2.csv` | 18-dimensional stroke-frequency features per game |

## Source data

The dataset is derived from two public releases:

- **ShuttleSet** — Wang, W.-Y., Huang, Y.-C., Ik, T.-U., & Peng, W.-C. (2023). *ShuttleSet: A human-annotated
  stroke-level singles dataset for badminton tactical analysis.* KDD '23.
- **ShuttleSet22** — Wang, W.-Y., Du, W.-W., Peng, W.-C., & Ik, T.-U. (2024). *Benchmarking stroke forecasting
  with stroke-level badminton dataset.* arXiv:2306.15664.

Please download them from their original releases and comply with their licences; they are not
redistributed here, and neither is the derived dataset.

## Rebuilding

```bash
# place the raw set*/match*.csv files under raw/
python build_dataset.py
```

Duplicated matches present in both releases are removed, leaving 94 matches, 223 games and 7,585 rallies.
